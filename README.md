# 한국사 영역 타임라인 (프로토타입)

초등 사회 5~6학년 역사 수업에서 쓰는 보조 자료다. 아래 막대를 375년부터 2026년까지 움직이면, 그때 한반도와 만주에 있던 나라들의 대략적인 세력 범위가 지도에 나타난다.

> **세력 범위는 대략적인 모습입니다.** 고대 나라의 영역은 정해진 국경이 아니라 힘이 미친 범위다. 점선은 학설이 갈리는 경계다. 최종 판단은 교과서와 대조한 교사가 한다.

## 여는 법

- `index.html`을 더블클릭해 브라우저(크롬 권장)로 연다. 네트워크가 없어도 된다(file://에서 모든 기능이 동작).
- 딥링크: `index.html?year=475`, `index.html?year=1950-08`
- 마지막으로 본 시점 하나만 브라우저 `localStorage`에 기억한다. 저장이 막힌 환경에서는 조용히 무시한다. 로그인·쿠키·통계·학생 입력 저장은 없다.

## 조작

| 조작 | 방법 |
|---|---|
| 시점 바꾸기 | 아래 막대를 끌거나 누른다. 한 해에 장면이 여러 장이면 그해 첫 장면을 보여 준다 |
| 이전/다음 장면 | ◀ / ▶ 버튼, 키보드 ← / → (같은 해 안의 장면도 한 장씩) |
| 재생/정지 | 왼쪽 아래 ▶ 버튼, 키보드 Space. 속도 버튼으로 0.5×·1×·2×·4×. 시대가 바뀔 때만 잠깐 멈춘다(1×로 처음부터 끝까지 약 1분 45초) |
| 나라 강조·소개 | 왼쪽 위 범례나 지도 위 나라를 누른다(마우스는 올리기만 해도 강조) |
| 바로 앞 장면 경계 | 범례의 "바로 앞 장면 경계" 상자. 바뀐 경계만 빨간 점선으로 보인다 |
| 지도 확대 | ＋/－/⟲ 버튼, 마우스 휠, 두 손가락 벌리기, 끌어서 옮기기 |
| 설명 패널 | 패널 왼쪽 가장자리의 › 탭으로 접고 편다 |
| 사건으로 가기 | 오른쪽 패널의 사건을 누르면 그 시점으로 간다 |

화면은 전자칠판(1920×1080), 태블릿 가로(1024×768, 1180×820), 크롬북(1366×768)에 맞췄다. 휴대폰 세로 화면은 대상이 아니다.

## 데이터 원칙

- 현행 초등 사회 교과서와 국사편찬위원회 서술을 따른다. 학계 소수설과 외국 측 서술은 넣지 않는다.
- 나라 영역은 기존 역사 경계 데이터셋 없이, 하천·산맥·해안 같은 지형 기준점과 교과서 서술을 근거로 새로 그린 도식 폴리곤이다. 도형마다 `basis`(근거)가 있다.
- 학설 차이가 큰 경계(고구려 전성기 서쪽, 발해 북쪽, 고려·조선 초 북방)는 `confidence: "논쟁"`으로 두고 점선으로 그린다.
- 독도·동해는 대한민국 공식 표기를 쓴다. 1449년 이후 모든 장면에 독도가 있다(512년 우산국 복속 이후 장면에도 있다).
- 일제 강점기는 '일본 영토'로 칠하지 않고 "일제 강점"(빗금) 영역으로 표시한다.
- 임나일본부설, 동북공정 측 서술, 한사군·안동도호부 영역은 지도와 글 어디에도 없다. `scripts/check.mjs`가 이를 자동으로 검사한다.
- 주변 세력은 회색 면과 작은 이름표로만 둔다.
- 영역이 바뀌지 않은 사건(임진왜란, 병자호란, 개항, 3·1 운동 등)은 장면을 만들지 않고 패널의 사건 목록에 넣었다.
- 출처와 가공 방법은 [data/SOURCES.md](data/SOURCES.md)에 있다.

## 폴더

```
index.html          화면
css/style.css       모양 (시스템 한글 글꼴만 씀)
js/model.js         시간·장면 계산 (검사 스크립트도 같은 코드를 씀)
js/map.js           메르카토르 투영과 SVG 지도
js/app.js           타임라인·범례·패널·키보드
data/*.geojson      원본 데이터, data/content.json 화면 글
data/data.js        빌드 결과 (직접 고치지 않음)
scripts/            빌드·검사·스크린샷 스크립트 (Node만 있으면 됨, npm 설치 없음)
review/             검토 기록, 스크린샷, Gemini 검토 원문
REVIEW.md           검토 결과와 사람이 확인할 항목
```

## 데이터를 고친 뒤

```bash
node scripts/build-data.mjs
```

```bash
node scripts/check.mjs
```

```bash
node scripts/screenshots.mjs
```

- `build-data.mjs`: `data/*.geojson`, `data/content.json` → `data/data.js`. `--ne <Natural Earth 폴더>`를 주면 바탕 지도도 다시 자른다.
- `check.mjs`: GeoJSON 유효성, 모든 연도·월의 장면 유무, 필수 속성, 존속 연도와 장면 범위, 표기 원칙, 외부 요청 여부를 검사한다.
- `screenshots.mjs`: 시스템 Chrome 헤드리스로 해상도별·장면별 스크린샷을 `review/`에 만든다.

나라 도형은 [geojson.io](https://geojson.io) 같은 편집기로 `data/s-<키>.geojson`을 열어 고칠 수 있다. 이웃 나라와 맞닿은 꼭짓점은 같은 좌표를 유지해야 틈이나 겹침이 생기지 않는다.

## GitHub Pages로 배포하기 (사람이 할 일)

이 저장소는 로컬 git 커밋까지만 되어 있다. 배포는 다음 순서로 한다.

1. GitHub에서 새 저장소를 만든다(예: `korean-history-timeline`). README나 .gitignore는 추가하지 않는다.
2. 이 폴더에서 원격을 연결하고 올린다.

```bash
git remote add origin https://github.com/<계정>/korean-history-timeline.git
```

```bash
git push -u origin main
```

3. 저장소의 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 `main` / `/(root)`로 고르고 저장한다.
4. 1~2분 뒤 `https://<계정>.github.io/korean-history-timeline/`에서 열린다. 빌드 단계는 없다(`data/data.js`가 커밋되어 있어야 한다).
5. 라이선스는 아직 정하지 않았다. 공개하기 전에 정한다(바탕 지도 Natural Earth는 퍼블릭 도메인).

## 만들지 않은 것

고조선과 그 이전, 군현·행정구역·도시, 이동 경로, 퀴즈, 음성, 다국어, 검색, 지형 음영, 타임라인 자르기, 임베드, 교사/학생 모드 전환, 학생 입력 저장, 휴대폰 세로 화면.

참고한 앱: [DeanChensj/jiangshan-map](https://github.com/DeanChensj/jiangshan-map)의 화면 배치와 조작감만 참고했다. 코드와 데이터는 한 줄도 가져오지 않았다.
