# 한국사 영역 타임라인 (프로토타입)

초등 사회 5~6학년 역사와 중학교 '역사'의 한국사 영역 수업에서 쓰는 보조 자료다. 아래 막대를 기원전 400년부터 2026년까지 움직이면, 그때 한반도와 만주에 있던 나라들의 대략적인 세력 범위가 지도에 나타난다.

> **세력 범위는 대략적인 모습입니다.** 고대 나라의 영역은 정해진 국경이 아니라 힘이 미친 범위다. 점선은 학설이 갈리는 경계다. **교과서 서술을 따르되 교과서마다 조금씩 다를 수 있어요.** 최종 판단은 자기 교과서와 대조한 교사가 한다.

## 여는 법

- `index.html`을 더블클릭해 브라우저(크롬 권장)로 연다. 네트워크가 없어도 된다(file://에서 모든 기능이 동작).
- 수준: 주소 뒤에 `?level=middle`을 붙이면 중학교 글, 없으면 초등 글이다. 화면 안에 전환 버튼은 없고, 중학교일 때 제목 옆에 "중학교"가 보인다.

| 열 주소 | 보이는 것 |
|---|---|
| `index.html` | 초등, 처음(또는 직전에 본 시점) |
| `index.html?level=middle` | 중학교 |
| `index.html?year=475` | 초등, 475년 |
| `index.html?year=-108` | 초등, 기원전 108년 (기원전은 음수, 0년은 없음) |
| `index.html?level=middle&year=1950-08` | 중학교, 1950년 8월 |

- 마지막으로 본 시점 하나만 브라우저 `localStorage`에 수준마다 따로 기억한다. 저장이 막힌 환경에서는 조용히 무시한다. 로그인·쿠키·통계·학생 입력 저장은 없다.

## 조작

| 조작 | 방법 |
|---|---|
| 시점 바꾸기 | 아래 막대를 끌거나 누른다. 한 해에 장면이 여러 장이면 그해 첫 장면을 보여 준다 |
| 막대 눈금 | 시대 띠 10개가 각자 정해진 너비를 차지하고, 띠 안에서는 연도를 고르게 나눈다. 연도 눈금은 띠마다 따로 찍는다 |
| 이전/다음 장면 | ◀ / ▶ 버튼, 키보드 ← / → (같은 해 안의 장면도 한 장씩) |
| 재생/정지 | 왼쪽 아래 ▶ 버튼, 키보드 Space. 속도 버튼으로 0.5×·1×·2×·4×. 막대 위를 고른 빠르기로 중간에 멈추지 않고 지나간다(1×로 처음부터 끝까지 90초, 4×로 약 23초) |
| 이름표 크기 | 우리 역사 나라 이름표는 영역 넓이에 맞춰 크기가 달라진다(넓은 나라는 크게) |
| 나라 강조·소개 | 왼쪽 위 범례나 지도 위 나라를 누른다(마우스는 올리기만 해도 강조) |
| 도읍·전투 보기 | 범례의 "도읍·전투 보기" 상자(기본은 꺼짐). 그 해에 해당하는 도읍(검은 네모)과 전투(빨간 동그라미)만 보이고, 누르면 설명이 뜬다. 위치 학설이 갈리는 점은 점선 테두리 |
| 지도가 바뀔 때 | 바뀐 땅만 움직인다. 같은 땅의 주인이 바뀌면(예: 396년 한강 북쪽, 494년 부여) 색이 옛 나라 색에서 새 나라 색으로 넘어가고 테두리가 한 번 반짝인다. 장면이 바뀌면 옛 지도가 서서히 사라진다. 기기의 '움직임 줄이기' 설정이 켜져 있으면 움직이지 않는다 |
| 바로 앞 장면 경계 | 범례의 "바로 앞 장면 경계" 상자. 바뀐 경계만 빨간 점선으로 보인다 |
| 지도 확대 | ＋/－/⟲ 버튼, 마우스 휠, 두 손가락 벌리기, 끌어서 옮기기 |
| 설명 패널 | 패널 왼쪽 가장자리의 › 탭으로 접고 편다 |
| 사건으로 가기 | 오른쪽 패널의 사건을 누르면 그 시점으로 간다. 사건이 도읍·전투 자리와 이어져 있으면(예: 612년 → 살수 대첩) 지도 위 그 자리가 동심원으로 반짝이고 이름이 잠깐 보인다(점 층을 꺼 두어도 보임) |
| 장면 제목 | 장면이 바뀌면 지도 위쪽에 시대·제목·기간이 2초 동안 뜬다 |
| 지형 보기 | 범례의 "산과 들의 높낮이 보기" 상자(기본은 켜짐). 나라 색 위에 언덕 음영을 얹어 산줄기를 보인다. 끄면 지도 오른쪽 아래의 지형 자료 출처도 숨긴다 |
| 발표 모드 | 오른쪽 위 "발표 모드" 버튼. 패널·범례를 접고 이름표와 연도를 크게, 장면 제목을 지도 왼쪽 아래에 크게 둔다. 다시 누르면 원래대로 |

화면은 전자칠판(1920×1080), 태블릿 가로(1024×768, 1180×820), 크롬북(1366×768)에 맞췄다. 휴대폰 세로 화면은 대상이 아니다(가로 화면 권장).

## 데이터 원칙

- 국사편찬위원회 서술을 먼저 따르고, 검정 교과서들(중학교 역사 7종, 초등 사회 5~6 11종)의 공통분모만 그린다. 교과서마다 다른 부분은 '논쟁'(점선)으로 두거나 지도에서 뺀다. 특정 출판사 이름은 근거에 적지 않는다.
- 나라 영역은 기존 역사 경계 데이터셋 없이, 하천·산맥·해안 같은 지형 기준점과 교과서 서술을 근거로 새로 그린 도식 폴리곤이다. 도형마다 `basis`(근거)가 있다.
- 학설 차이가 큰 경계(고조선 전체, 고구려 전성기 서쪽, 발해 북쪽, 고려·조선 초 북방, 동북 9성)는 `confidence: "논쟁"`으로 두고 점선으로 그린다.
- 고조선은 비파형 동검·탁자식 고인돌 분포를 기준으로 한 문화 범위로 그리고 중심지는 표시하지 않는다. "기원전 2333년 건국"은 장면으로 만들지 않고 첫 장면 글에서 '기록에 따르면'으로 소개한다.
- 한 군현은 도형·이름표·회색 면 어느 것도 두지 않는다. 그 자리(대동강 유역·황해도)는 기원전 108년~313년 빈칸이다. '한 군현'·'낙랑군'이라는 말은 중학교 글에서만 쓴다.
- 간도는 우리 영토 색으로 칠하지 않고, 1900~1909 장면에 '간도(우리 민족이 많이 살던 곳)' 빗금 영역('논쟁')으로만 둔다. 1909 간도 협약은 사건으로 다룬다.
- 독도·동해는 대한민국 공식 표기를 쓴다. 512년 우산국 복속 이후 장면과 1449년 이후 모든 장면에 독도가 있다. 1905년 일본의 독도 편입은 영역 변화가 아니라 불법 행위로 사건·소개에서 다룬다.
- 일제 강점기는 '일본 영토'로 칠하지 않고 "일제 강점"(빗금) 영역으로 표시한다.
- 임나일본부설, 동북공정 측 서술, 한사군·안동도호부 영역은 지도와 글 어디에도 없다. `scripts/check.mjs`가 이를 자동으로 검사한다.
- 주변 세력은 회색 면과 작은 이름표로만 두고, 이름은 시대에 맞게 나눈다(연·진·한·흉노·선비·위·전진·후연·북위·수·당·송·거란·여진·금·몽골·원·명·청 등). 기원전 108년~313년 한반도 안에는 주변 세력 면이 없다.
- 영역이 바뀌지 않은 사건(임진왜란, 병자호란, 개항, 3·1 운동 등)은 장면을 만들지 않고 패널의 사건 목록과 도읍·전투 점에 넣었다.
- 출처와 가공 방법은 [data/SOURCES.md](data/SOURCES.md)에 있다.

```
index.html          화면
css/style.css       모양 (시스템 한글 글꼴만 씀)
js/model.js         시간·장면 계산, 연도↔막대 위치 변환, 수준 읽기 (검사 스크립트도 같은 코드를 씀)
js/map.js           메르카토르 투영과 SVG 지도
js/app.js           타임라인·범례·패널·키보드
data/*.geojson      원본 데이터(나라 도형 s-*.geojson, 도읍·전투 points.geojson), data/content.json 화면 글(초등·중등)
data/data.js        빌드 결과 (직접 고치지 않음)

REVIEW.md           검토 결과와 사람이 확인할 항목
```

## 데이터를 고친 뒤

```bash
node scripts/build-data.mjs
```

```bash
node scripts/check.mjs
```

```bash
node scripts/interact-check.mjs
```

```bash
node scripts/screenshots.mjs
```

- `build-data.mjs`: `data/*.geojson`, `data/content.json` → `data/data.js`. `--ne <Natural Earth 폴더>`를 주면 바탕 지도도 다시 자른다.
- `build-hillshade.mjs <타일 폴더>`: Terrain Tiles 64장 → `data/hillshade.png`(지형 음영). 타일은 저장소에 없으므로 다시 만들 때만 받는다(받는 곳은 `data/SOURCES.md`).
- `check.mjs`: GeoJSON 유효성, 모든 연도·월의 장면 유무, 필수 속성, 0년 없는 연도 계산과 연도↔막대 위치 변환, 수준별 글 규칙(문장 수·길이, 사건·질문 개수, 성취기준), 도읍·전투 점, 존속 연도와 장면 범위, 표기 원칙(수준별 금지어, 고조선·간도·한 군현 자리), 외부 요청 여부를 검사한다.
- `interact-check.mjs`: 시스템 Chrome 헤드리스를 DevTools 프로토콜로 조작해 file://에서 장면 이동, 막대, 재생, 딥링크(기원전·수준), 점 층, 수준 전환, 4개 해상도의 48px 조작 요소 등 53항목을 확인한다.
- `screenshots.mjs`: 해상도별 레이아웃(초등·중등)과 장면별 지도 스크린샷을 `review/`에 만든다.
- 나라 도형의 원본은 `scripts/draft-shapes.mjs`(공유 경계선을 이어 붙여 만듦)다. 고친 뒤 `node scripts/draft-shapes.mjs data`로 `data/s-*.geojson`을 다시 만든다. 도읍·전투 점의 원본은 `scripts/points-src.mjs`다.
- Gemini 검토 입력은 `node scripts/review-input.mjs`, 한 회 실행은 `sh scripts/review-run.sh <history|text> <elementary|middle>`.

`data/s-*.geojson`을 geojson.io 같은 편집기로 직접 고쳤다면, 그 뒤로는 `draft-shapes.mjs`를 돌리지 않는다(고친 내용이 사라진다). 이웃 나라와 맞닿은 꼭짓점은 같은 좌표를 유지해야 틈이나 겹침이 생기지 않는다.

## GitHub Pages로 배포하기 (사람이 할 일)

이 저장소는 로컬 git 커밋까지만 되어 있다. 배포는 다음 순서로 한다.

1. GitHub에서 새 저장소를 만든다(예: `korean-history-timeline`). README나 .gitignore는 추가하지 않는다.
2. 이 폴더에서 원격을 연결하고 올린다.

```bash
git remote add origin https://github.com/<계정>/korean-history-timeline.git
```

```bash
git push -u origin main
```

3. 저장소의 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 `main` / `/(root)`로 고르고 저장한다.
4. 1~2분 뒤 `https://<계정>.github.io/korean-history-timeline/`에서 열린다. 빌드 단계는 없다(`data/data.js`가 커밋되어 있어야 한다).
5. 라이선스는 아직 정하지 않았다. 공개하기 전에 정한다(바탕 지도 Natural Earth는 퍼블릭 도메인, 지형 음영의 Terrain Tiles는 출처 표기 조건).

## 만들지 않은 것
